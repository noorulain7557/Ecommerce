🛒 Premium MERN Stack E-Commerce Platform
A beautiful, responsive, and full-featured e-commerce web application built using the MERN (MongoDB, Express, React, Node.js) stack. This project features a clean and modern user interface styled with Bootstrap 5, integrated state management, and an administration dashboard workspace panel to manage products, categories, and stock inventories.

✨ Features
👤 User Interface & Experience
Polished Modern Aesthetic: Interfaces use clean topography (Plus Jakarta Sans), responsive grids, elegant input transitions, and interactive cards.

Dynamic Client-Side Routing: Managed seamlessly through react-router-dom.

Persisted User Authentication: Multi-tier dashboards (Admin vs. User profiles) utilizing secure token verification.

🛡️ Admin Dashboard (/dashboard/admin)
Inventory Intake Console: Create and list new e-commerce inventory items with beautiful drag-and-drop styled photo uploading triggers, real-time image previews, dynamic textareas, and integer inputs.

Interactive Catalog Operations: View, modify, or completely purge inventory records with custom warning checks and instant database synchronizations.

Manage Categories: Organize listing structures cleanly using an embedded visual selection component schema.

👥 User Dashboard (/dashboard/user)
Profile Identity Hub: Structured visual credentials ledger displaying handle name, email, and location/shipping data.

Purchase History: Navigate, track, and monitor fulfillment logistics.

⚙️ System Components Included
Layout Wrapper: Implements sticky footer mechanics using standard flexbox definitions to ensure layout elements fit the viewport dynamically.

Sidebar Portals: Navigation sidebars (AdminMenu, UserMenu) highlighting currently selected route markers dynamically.
